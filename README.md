# Three.js Glass

Wired, hammered glass in front of a swaying plant, built with three.js shaders.

- Move the pointer to move the light.
- Press and hold to push the pane in: it tilts in 3D, the plant shifts behind it, and fog spreads.
- **Image** (or drag and drop) swaps the background for your own photo; **Plant** switches back.

```bash
pnpm install
pnpm dev
```
