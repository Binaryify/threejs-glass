# Three.js Glass

Wired, hammered glass in front of a swaying plant, built with three.js shaders.

- Press and drag to turn the whole pane: the reflection of a fixed light sweeps across the glass and the plant shifts behind it.
- Let go and the pane swings back.
- **Image** (or drag and drop) swaps the background for your own photo; **Plant** switches back.

```bash
pnpm install
pnpm dev
```
